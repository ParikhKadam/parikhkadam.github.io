03 Approach

How I work

  1. Measure the measurement

    Run the baseline more than once before trusting any before-and-after comparison. See it in practice

  2. Test the obvious fix

    The intuitive improvement is sometimes the one that hurts. Check it with a controlled comparison first. See it in practice

  3. Find the waste

    Quantify what a pipeline repeats or discards before adding more model calls. See it in practice
