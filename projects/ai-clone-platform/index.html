Persona architecture for creator AI clones

A platform that lets creators and influencers build an AI version of themselves from their face, voice and personal background, and hold conversations with fans. My part: the design that keeps every creator’s clone consistent, and remembering what matters about them.

Context
Creator-economy platform
My role
Onboarding design, clone pipeline, prompt architecture, memory, evaluation
Stack
Azure OpenAI, Soul Machines, Deepgram, ElevenLabs, Langfuse
Focus
Lorebook-style agent memory

Two design decisions

A creator cannot hold a one-on-one conversation with every fan. A clone that carries on authentic conversations at scale has to behave the same way for every creator, and remember the creator’s life across many separate conversations.

  • One template, many creators. A single standardized prompt template, with creator-specific content injected dynamically, means no creator needs a hand-written prompt. Changing persona behavior becomes a template edit, not a rewrite.
  • Lorebook-style memory. I built the memory stores that let a clone recall a creator’s life events across conversations, not only within one session. Memory is managed the way roleplay platforms manage a lorebook: a background fact enters the prompt only when the conversation triggers it, so the prompt does not carry the whole backstory.

What else I did

  • Designed the onboarding flow, starting from what creators wanted reflected in their avatar, to make collecting face, voice and personality inputs easy.
  • Built and optimized the automated clone-creation pipeline, and integrated a specialist avatar vendor for the face and voice, instead of building that multimodal capability in-house.
  • Validated the real-time streaming response pipeline end to end.
  • Built an LLM-as-a-judge evaluation framework for conversational quality and persona fidelity.

Why memory is lorebook-style

Injecting a creator’s full backstory into every prompt is the simple option, and it does not scale as backstories grow. I built memory management the lorebook way instead, the technique roleplay platforms use:

Every fact goes into every prompt, whatever the fan asks.

A fact is surfaced only when the conversation triggers it. Example: a fan asks about “your last trip”.
